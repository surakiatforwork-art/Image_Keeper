# Image Keeper v1.4.0-beta.17 — Cloud image aspect alignment hotfix

**แก้ไขปัญหาที่ผู้ทดสอบพบ:** AILabTools แสดงสถานะการเรียก AI Beard Removal สำเร็จ แต่ Image Keeper Beta 16 ปฏิเสธผลว่า "Cloud เปลี่ยนสัดส่วนภาพมากเกินไป" โดยการประมวลผล Cloud สำเร็จแล้วและอาจมีค่าใช้จ่ายไปแล้ว

## สิ่งที่แก้
- ไม่บังคับให้ภาพจาก AILabTools มีอัตราส่วนกว้าง:สูงเท่ากับภาพครอปที่ส่งไป จึงรองรับกรณีส่งภาพแนวตั้งแล้ว Cloud ส่งผลกลับเป็น **ภาพสี่เหลี่ยมจัตุรัส**
- ตรวจจุดสำคัญบนใบหน้าของภาพเดิมและผล Cloud แล้วหา **similarity transform** (เลื่อน / หมุน / ขยายย่อแบบสัดส่วนคงที่) จัดตำแหน่งให้ตรงกับต้นฉบับ แทนการยืดภาพแบบผิดสัดส่วน
- ตรวจความคลาดเคลื่อนของตา จมูก ปากหลังจัดแนว หากรูปหน้าถูกเปลี่ยนอย่างมากจะปฏิเสธผลเพื่อป้องกันการบิดเบี้ยว
- จัดวางเฉพาะบริเวณหนวดเคราบนสำเนาภาพ โดยรักษาริมฝีปาก ขอบคางและฉากหลังตามต้นฉบับ
- ไม่เอาพื้นที่โปร่งใสซึ่งอยู่นอกภาพ Cloud ที่จัดแนวมาแปะเป็นสีดำบนต้นฉบับ
- ยังคงโหมด AttGAN ออฟไลน์และข้อกำหนดความยินยอมอัปโหลดภาพ / API Key ของผู้ใช้ไม่บันทึกลงเครื่อง

## ตรวจสอบ
- `versionName=1.4.0-beta.17`, `versionCode=35`, package `com.branchphotovault`
- Android Gradle `:app:assembleDebug` สำเร็จ
- JVM tests ทั้งหมด **22 ผ่าน / ไม่มีข้อผิดพลาด** รวมการทดสอบจัดแนวกรณีภาพ Cloud เป็นสี่เหลี่ยมจัตุรัส การหมุนภาพ การปฏิเสธใบหน้าที่ผิดรูป และจุดสำคัญผิดปกติ
- **ยังไม่ได้ทดสอบ API จริงหรือ APK ใหม่บนเครื่องทดสอบที่ถอดสายออกแล้ว** ดังนั้นยังไม่ยืนยันผลลบหนวดจาก Cloud ว่าใกล้เคียง Meitu

## วิธีติดตั้งและทดสอบ
1. ติดตั้ง `Image-Keeper-v1.4.0-beta.17.apk` จาก GitHub Release ทับ Beta 16 (ควรสำรองข้อมูลก่อน)
2. เปิดภาพ → **รีทัชหนวดและเครา** → **Cloud AI · Beta**
3. ใส่ AILabTools API Key ของตัวเอง และยืนยันก่อนส่งภาพขึ้น Cloud
4. ตรวจว่าคราวนี้แอปรับภาพกลับและจัดตำแหน่งใบหน้าได้ก่อนบันทึก พร้อมซูมตรวจหนวด สีผิว และแนวคาง

**ข้อสำคัญ:** หากการส่งภาพใน Beta 16 ประมวลผลสำเร็จและถูกคิดค่าบริการแล้ว การกดประมวลผลภาพเดิมใหม่อาจมีการคิดค่าบริการอีกครั้ง Beta 17 ยังไม่มีปุ่มเรียกคืนผลจาก task_id เดิม

**ลายเซ็น:** APK debug-signed สำหรับทดสอบเหมือน Beta 16 ไม่ใช่ Stable Release; อย่าถอนการติดตั้งหากมีข้อมูลในแอปที่ไม่ได้สำรอง
