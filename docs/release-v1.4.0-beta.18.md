# Image Keeper v1.4.0-beta.18 — Offline AttGAN Quality Lab

**สถานะ:** Beta / Offline-only facial hair retouch, no paid API, no photo upload.

## ผู้ใช้เลือกแนวทางใหม่
ยกเลิก AILabTools Cloud Beard Removal เนื่องจากมีค่าใช้จ่ายและผลลัพธ์ยังไม่ใกล้ Meitu ที่ต้องการ กลับมาใช้โมเดล AttGAN ที่มีใน APK และปรับคุณภาพจากระบบออฟไลน์

## สิ่งที่เปลี่ยน
- ถอด Cloud AI, API Key, ปุ่มยินยอมอัปโหลด, การส่งภาพไป AILabTools และคลาส CloudBeard* / CloudFaceAlignment* ออกจากแอป
- UI เหลือ **AttGAN ออฟไลน์** เป็นวิธีหลักเท่านั้น (ค่าเริ่มต้นเหมือนผลเดิมที่ผู้ใช้เลือกให้ผ่าน)
- เพิ่มสวิตช์ **เก็บหนวดตกหล่นเพิ่มเติม (ทดลอง)**; ปิดเป็นค่าเริ่มต้นเพื่อไม่เปลี่ยนผล AttGAN ที่ยอมรับแล้วโดยไม่ตั้งใจ
- สวิตช์ทดลองรัน **โมเดล AttGAN เดิมเป็นครั้งที่สอง** โดยขยับกรอบใบหน้าในโมเดล 25 พิกเซล แล้วปรับเฉพาะผลต่างเล็กน้อยภายใน Mask เดิม
- ค่าผลต่างถูกจำกัดไม่เกิน ±20 ระดับต่อช่อง RGB และผ่านตัวป้องกันแนวคาง, feather ภายใน Mask, ไม่แตะภาพนอก Mask, ไม่ใช้คลาวด์
- เก็บความแรง/แปรงแต่งและคืนต้นฉบับไว้เหมือนเดิม; บันทึกภาพฉบับแต่งเป็นสำเนา

## ผลห้องทดลอง (Meitu visual proxy, ไม่ใช่ไฟล์กล้องต้นฉบับ)
จากไฟล์อ้างอิงของผู้ใช้บนมือถือ (ภาพก่อนมาจากวิดีโอที่นำมาจัดแนว ไม่ใช่ JPEG กล้อง):
- AttGAN รอบเดียว: RGB mean error ในพื้นที่อ้างอิงที่ Meitu แก้ชัดเจน: **9.039**
- AttGAN + second view offset -25 / weight 0.60: **7.581** (ต่างลดลงราว 16% ในกรณีนี้)
- weight 1.0: 6.960 แต่เพิ่มโอกาสเปลี่ยนโทนผิวมาก จึงเลือก **0.60** เป็นตัวทดลองอนุรักษ์นิยม
- ทดลอง shift/scale 10 แบบและน้ำหนัก 3 ระดับรวม 30 variants; ผลออกมาไม่เท่ากันทุกกรณี — ไม่ถือว่าผ่านคุณภาพโดยอัตโนมัติ
- ภาพเปรียบเทียบ: research/clean_shave_lab/metrics/attgan_multiview/side_by_side.jpg
- คะแนน JSON: research/clean_shave_lab/metrics/attgan_multiview/scores.json
- **สำคัญ:** ค่าภาพต่างไม่สามารถใช้แทนการประเมินด้วยสายตา; ผู้ใช้เคยเลือก AttGAN เดิมว่าใกล้ Meitu ที่สุด จึงยังเก็บผลเดิมเป็นค่าเริ่มต้น

## การตรวจสอบเชิงเทคนิค
- แก้ไข Kotlin โดยไม่แตะโมเดล AttGAN / Face Parser หรือไฟล์ภาพต้นฉบับ
- เพิ่ม JVM tests: AttganDetailBlendTest สำหรับความถูกต้องของการเบลนด์, น้ำหนักศูนย์, ขอบเขต ±20 RGB, ค่าผิดปกติ
- เพิ่ม Android instrumentation regression source (ยังไม่ได้รันบนมือถือ): OfflineAttganDetailIntegrationTest วัดผลนอกใบหน้าและ bounds
- Gradle :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest ผ่าน (ขึ้นกับผลสั่งสร้างรอบสุดท้าย)
- ตั้งใจ **ไม่ติดตั้งผ่าน ADB บนมือถือหลัก** เพื่อหลีกเลี่ยงการกระทบข้อมูลของผู้ใช้ที่ไม่ได้อนุญาตให้ใช้เป็นเครื่องทดสอบรอบนี้

## ความเป็นส่วนตัวและต้นทุน
- ไม่มีการเรียก AI Cloud และไม่ต้องใส่ AILabTools API Key
- แอปส่วนอื่นที่ใช้ Google Apps Script สำหรับจัดการสาขา/รูปภาพยังอาจใช้สิทธิ์อินเทอร์เน็ตตามฟังก์ชันของแอป ไม่ได้อ้างว่าแอปทุกฟังก์ชันทำงานออฟไลน์
- ไม่ได้ส่งข้อมูลหรือรูปภาพส่วนตัวไป GitHub; ห้องทดลองและไฟล์ภาพส่วนตัวอยู่เฉพาะ PC และถูก gitignore

## ข้อจำกัดและการใช้งาน
- ระบบสองมุมมองเป็น **ทดลอง**; อาจช่วยภาพที่หนวดตกหล่น แต่ยังไม่รับรองว่าดีกว่าระบบเดิมกับทุกใบหน้า
- โหมด AttGAN รอบเดียวเป็นหลักที่รักษาพฤติกรรมเดิมอย่างเข้มงวด
- ให้เปรียบเทียบกับ Meitu ก่อนเลือกใช้โหมดทดลอง, ตรวจแนวกรามและสีผิว, และเก็บต้นฉบับก่อนทดลอง
- รุ่นนี้ยังไม่ได้ฝึกโมเดลใหม่ หรือพิสูจน์ผลกับใบหน้าหลากหลายประเภททั่วถึง
