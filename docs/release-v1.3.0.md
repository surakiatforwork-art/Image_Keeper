# Image Keeper v1.3.0

- Pinch to zoom up to 6x and pan in the photo viewer and moustache/beard retouch preview. Double-tap resets to the original fit size.
- New Premium Minimal Liquid Glass design: lavender/ice-blue backdrop, translucent cards, purple primary buttons, compact branch list, square gallery thumbnails and a photo filmstrip.
- Retouch controls are now presented in a glass bottom sheet; original photos remain untouched and edited copies are saved separately.
- New mint ghost launcher icon and bundled offline Thai typography.
- Supports system light/dark appearance. Image content keeps its original aspect ratio and colors.

Existing branch metadata, capture, imports/exports, retention settings, sync and sending to GhostShift/Timestamp are retained. No database migration or app identity change.

Validation includes zoom state unit tests, on-device pinch/reset and pager gestures, real retouch sheet gestures, offline model smoke tests and the supplied private photo regression set. Personal test photos are not included in the app or release.
