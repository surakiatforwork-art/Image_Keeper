# Image Keeper v1.4.0-beta.16 — Cloud Beard Removal (ทดลอง)

สถานะ: **GitHub Pre-release / Beta**
APK: `Image-Keeper-v1.4.0-beta.16.apk`
Package: `com.branchphotovault` — `versionCode=34`.

## สิ่งที่เพิ่ม

- โหมด **Cloud AI · Beta** ใช้ AILabTools AI Beard Removal แบบ asynchronous (ส่งภาพ → ติดตาม task → ดาวน์โหลดผล)
- โหมด **AttGAN ออฟไลน์** เป็นค่าเริ่มต้นและตัวเลือกหลักที่รักษาคุณภาพจากงานทดลองเดิม
- ขอความยินยอมก่อนส่งภาพทุกครั้ง และระบุค่าบริการ/ความเป็นส่วนตัว
- ส่งเฉพาะ **ภาพครอปใบหน้าที่เลือก** และลดขนาดสูงสุดประมาณ 1500 พิกเซล ไม่ส่งเต็มภาพโดยไม่จำเป็น
- ใช้ผล Cloud เฉพาะผิวส่วนล่างของใบหน้า โดยคงขอบคาง ริมฝีปาก จมูก เสื้อ ฉากหลังจากต้นฉบับ
- ตรวจตำแหน่ง Landmark หลังประมวลผล หากใบหน้า/ริมฝีปากเคลื่อนมากผิดปกติจะปฏิเสธผลลัพธ์
- ใช้ API Key ของผู้ใช้เอง (BYOK) **ไม่ฝังคีย์ใน APK ไม่บันทึกคีย์ลงดิสก์** และไม่มี API คีย์ของผู้พัฒนา
- รองรับการยกเลิกรอผล แต่หากส่งงานไปแล้วอาจยังเกิดค่าใช้จ่ายกับผู้ให้บริการ

## วิธีทดลอง

1. สมัครและสร้าง API Key ที่หน้า AILabTools Developer: https://www.ailabtools.com/docs/get-api-key/
2. ติดตั้ง APK จาก **GitHub Releases** และเปิดภาพใน Image Keeper
3. เข้าเมนู **รีทัชหนวดและเครา** → เลือก **Cloud AI · Beta**
4. วาง API Key ที่ช่องรหัส (จะไม่แสดงตัวอักษรและไม่บันทึกข้ามการปิดหน้าต่าง)
5. กด **ลบหนวดด้วย Cloud AI (Beta)** และอ่านเงื่อนไขก่อนกดยินยอมอัปโหลด
6. เมื่อภาพกลับมา ให้ตรวจหนวดด้านข้างริมฝีปาก สีผิว รูปคางและคอ และความคมชัด แล้วจึงบันทึกฉบับแต่ง (เป็นไฟล์ใหม่ ต้นฉบับไม่ถูกแก้)

## ข้อจำกัดและข้อควรระวัง

- **ยังไม่ได้ทดสอบคุณภาพ Cloud ผลจริงจาก API** เนื่องจากไม่มีคีย์ที่ได้รับอนุญาตให้เรียก API; การ Build และ Unit Tests ผ่าน แต่ end-to-end กับผู้ให้บริการยังไม่ได้รับการยืนยัน
- **ยังไม่สามารถยืนยันว่าลบหนวดได้เทียบเท่า Meitu** จากต้นฉบับเดียวกัน ห้ามใช้ค่า MAE หรือผลจากวิดีโอเพียงอย่างเดียวเป็นเกณฑ์ผ่าน
- AILabTools อาจคิดค่าบริการต่อภาพ และเก็บข้อมูล/ผลลัพธ์ตามนโยบายของตน; URL ผลลัพธ์ของงาน async มีอายุ 24 ชั่วโมงตามเอกสาร
- ถ้าภาพ Cloud เปลี่ยนองค์ประกอบหรือสัดส่วนมากเกินไป แอปจะไม่ใช้ภาพนั้น
- เนื่องจากเครื่องทดสอบจะถูกถอดสาย ADB เวอร์ชันนี้ทดสอบบน Gradle/JVM และ compile Android test เท่านั้น **ยังไม่ได้ทดสอบการทำงานจริงบนมือถือหลังการรวม Cloud**
- รุ่นนี้ไม่ส่งโมเดล Beard Segmentation ที่มีสิทธิ์ข้อมูลฝึกยังไม่ได้ตรวจสอบ ซึ่งเคยใช้ใน V4.1; ตัวเลือก V4.1 ถูกซ่อนโดยตั้งใจ
- APK **debug-signed** สำหรับทดสอบ หากเครื่องมี Image Keeper ที่ลงด้วยใบรับรองลายเซ็นอื่น อัปเดตทับไม่ได้ ห้ามถอนติดตั้งโดยไม่สำรองข้อมูลภาพ/ฐานข้อมูลของแอป
